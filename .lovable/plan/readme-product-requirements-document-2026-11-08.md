# README Product Requirements Document

Rewrite only the existing `README.md` as a product requirements document for the business-site template editor.

## Requirements to capture
- Product purpose, target users, and the goal of quickly creating distinct but structurally related websites for businesses in the construction-equipment and adjacent vendor category.
- A clear content hierarchy: a **page** is a navigable destination such as Home, About, Services/Equipment, Projects, or Contact; a **section** is a configurable content block within any page, including Home, About, or Services.
- Page-level and within-page section customization: choose, order, and edit reusable, generic content blocks appropriate to each vendor, rather than treating About, Projects, Equipment, and Contact as section types.
- Brand controls, template/style choices, live preview, and export of a lightweight standalone HTML file with embedded styles, scripts, and selected images.
- Product scope, functional requirements, quality requirements, acceptance criteria, and known open questions or limitations. Mark proposed capabilities separately from what the current editor visibly implements.

## Constraints
- Change the existing README only; do not change application code, other project files, or backend behavior.
- Preserve relevant project guidance: this is a focused, client-side editor for portable business websites, not a full website builder; the export is intended to omit the editor runtime.
